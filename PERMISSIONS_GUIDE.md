# HVL Materials Management System - Permissions Guide

## Role-Based Access Control (RBAC)

### 👤 Admin
**Focus:** User management and system oversight

**Permissions:**
- ✅ View inventory (read-only)
- ✅ View material requests (read-only)
- ✅ View IN/OUT transactions (read-only)
- ✅ **Manage users** (add, edit, delete, assign roles)
- ✅ View activity logs
- ✅ Manage system settings
- ❌ Cannot edit inventory
- ❌ Cannot approve/reject requests
- ❌ Cannot record IN/OUT transactions

**Dashboard Features:**
- System statistics
- User activity monitoring
- Low stock alerts
- Recent activity logs

**Settings Access:**
- **Full system settings** (security, backup, session timeout)
- Profile information
- Password change
- Notification preferences
- User management from Users page

---

### 📦 Warehouse Staff (Stockroom)
**Focus:** Material handling and physical inventory management

**Permissions:**
- ✅ View inventory
- ✅ **Edit inventory** (add, update, delete materials)
- ✅ **Record Material IN** (deliveries, receipts)
- ✅ **Record Material OUT** (approved releases only)
- ✅ View approved material requests
- ✅ **Print transaction receipts**
- ✅ View activity logs
- ❌ Cannot submit material requests
- ❌ Cannot approve/reject requests
- ❌ Cannot manage users

**Dashboard Features:**
- Quick IN/OUT action buttons
- Approved requests ready for processing
- Low stock alerts
- Transaction summary

**Settings Access:**
- Profile information
- Password change
- Notification preferences (low stock alerts, system notifications)

**Key Responsibilities:**
- Process approved material requests
- Update inventory when materials arrive
- Release materials to projects after approval
- Maintain accurate stock levels

---

### 🔧 Engineer
**Focus:** Requesting materials for projects

**Permissions:**
- ✅ View inventory (read-only)
- ✅ **Submit material requests**
- ✅ View own request status
- ✅ Track request history
- ❌ Cannot edit inventory
- ❌ Cannot approve/reject requests
- ❌ Cannot record IN/OUT transactions
- ❌ Cannot see other engineers' requests

**Dashboard Features:**
- Material request form
- Personal request tracking
- Pending vs approved requests count
- Available inventory view

**Settings Access:**
- Profile information
- Password change
- Notification preferences

**Receipt Access:**
- **View and print approval/rejection receipts** for own requests
- Receipt button appears after manager reviews request

**Workflow:**
1. Check inventory availability
2. Submit material request with quantity, purpose, and date needed
3. Wait for Project Manager approval
4. Receive approval/rejection receipt (printable)
5. If approved: Collect materials from warehouse after processing

---

### 👔 Project Manager
**Focus:** Approve material requests and monitor resources

**Permissions:**
- ✅ View inventory (read-only)
- ✅ View all material requests
- ✅ **Approve material requests**
- ✅ **Reject material requests** (with reason)
- ✅ View IN/OUT transactions (read-only)
- ✅ View activity logs
- ❌ Cannot edit inventory
- ❌ Cannot record IN/OUT transactions
- ❌ Cannot submit material requests

**Dashboard Features:**
- Pending approvals queue
- Approval statistics
- Recent transaction monitoring
- Request details and history

**Settings Access:**
- Profile information
- Password change
- Notification preferences (low stock alerts, system notifications)

**Workflow:**
1. Review pending material requests
2. Check inventory availability
3. Approve or reject requests with reasons
4. **Approval/rejection receipt automatically displays** after decision
5. Monitor transaction history
6. Track resource allocation

**Activity Logged:**
- Request approvals
- Request rejections with reasons

**Receipt Generated:**
- Approval/Rejection receipt automatically generated after decision
- Contains request details, review information, and next steps
- Printable for engineer and project records
- Shows status, reason (if rejected), and acknowledgment section
- Engineer can also print this receipt from their request list

## Material Request Workflow

```
1. Engineer submits request
   ↓
2. Request appears in Manager's approval queue (real-time)
   ↓
3. Manager reviews and either:
   - Approves → Approval receipt generated + Request goes to Warehouse Staff
   - Rejects → Rejection receipt generated (with reason) + Engineer notified
   ↓
4. If approved: Warehouse Staff sees request in approved queue
   ↓
5. Warehouse Staff processes and records Material OUT
   ↓
6. Inventory automatically updated (quantity decreases)
   ↓
7. Transaction receipt printed for engineer pickup
   ↓
8. All actions logged in Activity Logs
```

**Receipts Generated:**
- **Approval/Rejection Receipt**: Generated by Manager when decision is made
- **Transaction Receipt**: Generated by Warehouse Staff when material is released

## Receipt System

### 1. Transaction Receipts (Material IN/OUT)

Every IN/OUT transaction generates a **printable receipt** containing:
- Transaction ID and type (IN/OUT)
- Date and time
- Material details (name, ID, quantity)
- Source/Destination
- Performed by (staff name)
- Notes/remarks
- Signature sections

**Who can print:**
- Warehouse Staff (after recording transaction)
- Project Manager (view-only, can print for records)
- Admin (view-only, can print for records)

### 2. Approval/Rejection Receipts (Material Requests)

When a Project Manager approves or rejects a material request, an **approval/rejection receipt** is automatically generated containing:
- Request ID and status (APPROVED/REJECTED)
- Request date and review date
- Requester and reviewer information
- Material details (name, quantity, purpose)
- Rejection reason (if applicable)
- Next steps for the engineer
- Acknowledgment signatures

**Features:**
- Automatically shown after approval/rejection decision
- Printable for engineer notification
- Professional format with color-coded status
- Clear next steps based on decision
- Full audit trail

**Who generates:**
- Project Manager (automatically when approving/rejecting)

## Activity Logs

All actions are automatically logged:
- Material additions/updates/deletions
- Material requests submitted
- Request approvals/rejections
- IN/OUT transactions
- User creation/modification/deletion

**Logged Information:**
- User ID and username
- User role
- Action type
- Timestamp
- Details/description
